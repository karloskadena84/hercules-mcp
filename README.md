# 🏛️ Hércules

**Optimiza el rendimiento de tu Windows o Mac de forma automática y segura.**

---

## Instalación en Windows (2 minutos)

1. Descomprime esta carpeta
2. Haz **doble clic** en:

   ```
   scripts\instalar.bat
   ```

3. Cuando termine:
   - Cierra Claude Desktop completamente
   - Ábrelo de nuevo
   - Escribe: `optimiza mi sistema`

El instalador prepara todo solo (incluido lo necesario la primera vez).

---

## Instalación en Mac

```bash
chmod +x scripts/install.sh
./scripts/install.sh
```

Reinicia Claude Desktop y escribe: `optimiza mi sistema`

---

## Uso

```
optimiza mi sistema
```

Hércules analiza tu equipo, te explica los resultados y te guía para:
- Liberar RAM y memoria en espera
- Limpiar espacio en disco
- Cerrar programas pesados
- Encontrar archivos grandes
- Activar el plan de energía de alto rendimiento
- Reducir programas de inicio

Siempre pide confirmación antes de cambiar nada.
